`apply_redaction!` gains an opt-in `shape_mode: "match_attribution"` that resolves shape enforcement per record from the in-proto or envelope workspace, account and metastore ids, checked against the `fedramp_allowlist` enrichment table, with optional `keep_original`, `shard_name` and `allowlist_refresh_secs` arguments; the default behavior is unchanged. The redaction executor gains the matching ABI entry points and syncs the vendored plan proto with `ModeSwitch`, so PUID lookups are detected inside mode-switch arms. `wire_to_arrow` maps message-typed fields whose Arrow column is BINARY (not a struct) to `LargeBinary` or `List<LargeBinary>` columns, and coerces int64 millisecond values to `Date32` and ISO-8601 strings to `Timestamp`, matching classic date handling. Only pairings that previously failed plan build are affected.
