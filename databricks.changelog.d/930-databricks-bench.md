Add `benches/databricks`, a bench-only harness for checking Databricks Vector pipelines against a baseline, starting with Hydra metrics. `capture` records real traffic from a live pod into a corpus; local fakes of the S3, Unity Catalog and Zerobus endpoints record what a candidate's sinks write; `gen` replays a corpus into candidates; `verify` compares each candidate's sink output with the baseline, and `check` runs that whole correctness flow in one command. The core is pipeline-generic, with per-source codecs and per-sink kinds. Behind the new `databricks-benches` feature; no production code changes.
