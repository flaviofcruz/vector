Bound all admitted batches across retry backoff and fallback with a sink-wide request concurrency limiter; inherit per-pod limits with optional fixed/adaptive overrides. Add DEBUG refresh, aggregate pod-load, health-transition and fallback diagnostics plus optional TRACE request selections, with console filters documented for troubleshooting.
