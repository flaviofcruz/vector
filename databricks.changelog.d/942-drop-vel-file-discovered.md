Stop emitting `LOGGING_AGENT_FILE_DISCOVERED` to the Vector event log: the file source's "Found new file to watch." log (`FileAdded`) no longer carries `vector_event_type` / `vector_file_event_type`. `LOGGING_AGENT_FILE_READ_STARTED` follows within milliseconds for nearly every new file and carries the same fields plus the fingerprint and file stat, so emitting both doubled VEL file-event volume and exceeded the `vector-event-log` KPP byte-rate limit. The log line and `files_added_total` counter are unchanged. https://github.com/databricks-eng/vector/pull/942
