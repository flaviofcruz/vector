Add an opt-in, hidden `emit_read_delivery_events` option to the `vector` source that emits `VECTOR_SOURCE_READ` delivery events for diskless structured-log batches (`MESSAGE_TAG_STRUCTURED_MESSAGE`), counting each `structured_log_messages.structured_log_messages[]` element as one line with delivery method `VECTOR_WOODCHUCK_V2_DISKLESS`, topic (message, else batch; dash-cased like file reads), system (`log_entry.system_uri` without `system:`), and workload (`log_entry.pod_name`, else `pod_uid`); it stamps the read-time `time_parity` onto counted batches and emits only after the batch is admitted to the pipeline. Default behavior is unchanged. https://github.com/databricks-eng/vector/pull/923
