The Databricks bench gains a `bench` command for performance: it runs each candidate alone on half the box's cores, fenced off from every other process by a cgroup-v2 cpuset partition with a memory limit (made with passwordless sudo), with the load generator and the fakes on the other half, and reports each run's CPU, memory, throughput, flush time and rows delivered. `--repeat N` runs N rounds of every candidate in alternating order and summarizes each candidate's median and range. A run fails when it misses its target rate, or when a sink recorded no rows or a different count from the first run's.
