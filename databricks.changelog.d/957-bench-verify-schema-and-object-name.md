The Databricks bench's `verify` (and `check`) compares each row by its destination, metadata fingerprint and original bytes. Metadata is fingerprinted once per S3 object (normalized filename and detected codec) or decoded Zerobus Arrow schema as sent (ordered fields, nested types/nullability and metadata), then reused for its rows through the existing multiset comparison. Wrong schemas, S3 names/codecs, or swapped row/schema associations are DIFFERENT; examples show original rows and metadata hashes. Metadata-only empty objects/streams are not compared. https://github.com/databricks-eng/vector/pull/957
