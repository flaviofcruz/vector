Validate native Vector listener and Vector/KafkaProducerProxy sink TLS replacements before stopping the running topology, and retain parsed credentials for builds and rollback. Invalid or partially replaced certificate, key, or CA files leave the last-good topology running; repaired replacements can be picked up by the configured file watches without restarting the process. This preserves existing authentication, routing, and buffer behavior and does not assume atomic publication of the certificate/key/CA bundle. https://github.com/databricks-eng/vector/pull/974
