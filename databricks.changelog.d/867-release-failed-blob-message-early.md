Add opt-in `failed_message_visibility_timeout_secs` (`aws_s3` SQS) and `failed_message_ack_deadline_secs` (`gcp_gcs` Pub/Sub). When set, a request-level object fetch failure (`GetObject`, or `FetchObject` on GCS) shortens the message lease with `ChangeMessageVisibility` / `ModifyAckDeadline` so it is retried after that delay instead of the full visibility timeout or ack deadline. Default unset keeps current behavior; read and decode errors are unchanged. Emits `sqs_message_visibility_released_total` and `pubsub_message_ack_deadline_released_total`.
