Fix read-side `delivery_method` inference in `DeliveryReadEvent::emit`. `deliveryMethod` denotes *how the content was read* — `VECTOR_WOODCHUCK_V2_FILE` (read from files) vs `VECTOR_WOODCHUCK_V2_DISKLESS` (diskless gRPC) — not the topic type. 183. Make the `http` enrichment table fail open when its initial load fails at startup instead of crashlooping the process.
